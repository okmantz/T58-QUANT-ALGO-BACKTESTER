Overnight autopilot

One button: runs Speed Run's discover-then-validate search and, on a READY/MARGINAL winner, automatically starts a live MT5 demo forward test of it -- then writes one report you can read once it's done. This can't finish a full forward-test evaluation overnight (forward testing is a live, ongoing process) -- what you get is a completed search and, if it qualified, a winner already live and trading. The forward-test step only actually starts something if this server is running on the same Windows machine as a logged-in MT5 demo terminal; otherwise it's skipped with a clear note in the report, and you still get the full search + winner.
