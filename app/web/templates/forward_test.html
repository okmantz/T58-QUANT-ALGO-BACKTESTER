Forward test (MT5)

Runs your strategy live against a demo (or real) MT5 account's incoming bars, without risking a backtest's usual look-ahead assumptions. Works whenever THIS web server's own machine has a MetaTrader 5 terminal installed and logged in -- there's no way to reach an MT5 terminal on a different machine from a browser, but if you're running this app locally (the normal way to use it), that's exactly the same machine your MT5 terminal is on.
