Forward test (MT5)

This one stays desktop-only -- a platform constraint, not a bug.

Why this can't run here

The desktop app's Forward Test tab talks directly to a MetaTrader 5 terminal running on the same Windows machine, via the MetaTrader5 Python package -- which itself only works on Windows, and only against a terminal that's actually installed and logged in locally. There's no web equivalent of "the MT5 terminal on your desk" to connect to from a phone browser.

What this means practically

  • Use the T58-Quant-Algo-Backtester.exe (or `python -m app.main`) on Windows for live/demo MT5 forward testing -- that tab works exactly as before.
  • Everything else in this app -- backtesting, Full Pipeline, Search Lab, the Validation Lab tabs, Evolution Lab, the Strategy Library -- works identically whether you're on the desktop app or this web app.

If real web-based forward testing matters to you later

The honest options, if this becomes a priority:

  • Leave it desktop-only permanently (simplest, no new moving parts).
  • Build a small always-on Windows relay service (running wherever a real MT5 terminal lives) that this web app talks to over the network instead of importing the MT5 package directly -- a real project in its own right, not a quick port.
