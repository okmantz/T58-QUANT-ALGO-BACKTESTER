How this works
  1. Once: install MetaTrader 5 (64-bit) from your broker or prop firm, open it, and log in to a demo account. Save that account under Settings → API Keys → Brokers/Prop Firms.
  2. Pick the account, symbol and strategy below, then press Start forward test.
  3. T58 does the rest: sets up its connection helper (first time only), opens MT5 if it is closed, logs in, checks that Algo Trading is on, and starts your strategy. It trades by sending orders to MT5 itself, so you never build or attach an Expert Advisor.
  4. If anything stops it, a red card names the problem in plain words and lists the exact steps to fix it.
