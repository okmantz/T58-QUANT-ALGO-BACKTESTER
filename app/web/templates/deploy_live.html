Deploy live

Connects to a real broker/prop-firm account (MT5, cTrader, Tradovate, TradeLocker, DXtrade) and places real trades.

⚠ Read before using this page. This trades real money on a real account. Access control (v7): these routes are disabled entirely unless the server was started with T58_ENABLE_WEB_LIVE_DEPLOY=1 and an app-lock password is set under Account Settings with this browser session unlocked. Enabling the flag without the password lock keeps every route refused. If this page shows a "disabled" error, that is the guard working -- do not expose this server's port beyond localhost unless you understand exactly who can reach it.

Enforced prop guardrails (every web-launched session)

News blackout ON (07:25–07:40, 12:55–13:10 server/broker time -- US releases/FOMC) · weekend holds BLOCKED (flattened Friday) · hedging BLOCKED · max 5 contracts/lots per single order · daily-loss limit halts new entries · max-drawdown halt armed -- a breach flattens ALL positions and stops the session · 3 consecutive poll failures also flatten and halt. Sizing units are converted to broker-native quantity (whole contracts on Tradovate, lots elsewhere) -- never passed through raw.
