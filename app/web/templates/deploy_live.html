Deploy live

Connects to a real broker/prop-firm account (MT5, cTrader, Tradovate, TradeLocker, DXtrade) and places real trades.

⚠ Read before using this page. This trades real money on a real account. Two things are true at once here: (1) it works the same way the desktop app's Deploy Live tab does -- same broker connections, same execution engine -- whenever this web server runs on the same machine as your MT5 terminal (for MT5 accounts) or has network access to your broker's API (for the others); and (2) this web server, as configured, has no login of its own and listens on every network interface -- anyone who can reach this server on your network can open this page. If that matters to you (this server is reachable beyond just your own device), set a local app-lock password under Account Settings first, or don't expose this server's port beyond localhost.
