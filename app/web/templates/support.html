Frequently asked questions
How do I create a strategy?

Open Create. You have three routes: describe an idea in plain English or paste your own Python, PineScript or MQL5 code; build one rule by rule in the no-code Manual builder (Strategy Library); or let the Strategy Discovery Engine find candidates for you. Everything you save lands in the Strategy Library.

I don't have a strategy yet. What does the Discovery Engine do?

You pick a market and a prop firm, and the engine generates and screens many strategy candidates against that firm's rules, then keeps the survivors. Speed Run, Search Lab, Evolution Lab and the deep "Forge" gauntlet are now presets of the engine, so you no longer start in separate tools. A survivor is a lead, not a verdict: send it through Optimize and Validate before you trust it.

What is the order of the workflow?

Create → Test → Optimize → Validate → Champion → Deploy. Test runs one strategy on one dataset. Optimize tunes its numbers. Validate stress-tests the result. A strategy that passes the core checks can be promoted to Champion, and Deploy covers forward testing and going live.

What's the difference between Optimize and Full Pipeline?

Optimize runs a walk-forward-aware genetic search for better parameters and finishes in minutes. It never grants a READY verdict. Full Pipeline runs the complete process (baseline, search, final Monte Carlo, out-of-sample checks) and returns READY / MARGINAL / NOT READY. Run it before trusting a result.

Why is Optimize searching only part of my data?

Every candidate is a full multi-fold backtest, so run time grows with the number of bars. By default Optimize searches the most recent 150,000 bars and says so in the run log. Raise Max bars under Advanced options (0 = use everything), or pick a coarser timeframe. Population and generations in the same panel control how wide the search is.

Which validation tests can I run, and how do I run just one?

The Validate page lists all eight checks in one place: Monte Carlo, CPCV, PBO, Walk-forward, Walk-forward GA, Sensitivity, Robustness and Regime. Tick the ones you want and press Run. Tick one to run it alone, or all of them for the full battery.

What is the Strategy Graveyard?

It is the record of strategies that failed screening or validation, with the reason each was rejected. Search it before you re-test an idea, so you don't repeat work that already failed.

Why does a search say a candidate has zero trades?

The strategy's entry conditions never fired on that dataset/timeframe combination. Widen the parameter ranges, check the timeframe matches what the strategy expects, or try a different instrument.

Can I use MT5, cTrader, Tradovate, TradeLocker, or DXtrade?

Yes. Add an account under Settings → API Keys → Brokers/Prop Firms, then use Forward Test (demo) or Deploy Live from the Strategy Library's Deployments tab.

Where is my data saved?

Your runs, strategies, achievements and settings are saved on this computer and mirrored to a private vault filed under your license key, so they come back after a reinstall. Market-data files are not mirrored; re-import them from the Data section.

Report an issue
