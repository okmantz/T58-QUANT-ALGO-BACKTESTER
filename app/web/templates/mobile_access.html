If your phone says "site can't be reached"

  1. Make sure your phone and this computer are on the same Wi-Fi network (not cellular data, and not a guest/isolated Wi-Fi network — common in coffee shops, offices, and hotels).
  2. On Windows, the first time this server runs, Windows should prompt "Allow python.exe to communicate on Private networks?" — if you clicked Cancel/No, or the prompt never appeared, open Windows Security → Firewall & network protection → Allow an app through firewall and enable Python for Private networks.
  3. Check your PC's network is set to Private, not Public, in Windows network settings — Public profiles block incoming connections like this one by default.
  4. Temporarily disable any VPN on either device — a VPN can hide LAN traffic from the other device even when both are on the same physical Wi-Fi.
  5. Not actually at home / not on this Wi-Fi at all? That's expected — this address only works on the same network as this computer. Use the "Away from home (Tailscale)" card above instead.

This computer needs to stay on and this app needs to keep running for your phone to reach it — closing this browser tab doesn't stop the server, but closing the terminal window it was started from does.
