5. AI Assist (optional, off by default)

When enabled, the GA search asks a local Ollama model for candidate parameter values once per generation and seeds them into the population alongside the normal random/bred candidates. Every suggestion still goes through the exact same backtest/prop-sim/Monte Carlo evaluation as any other candidate -- it proposes numbers for parameters that already exist, never code. Needs Ollama reachable at the host below from wherever this server is running (works over your home/office LAN -- point it at the IP of whatever machine is running Ollama).

6. Or run on multiple saved strategies (batch)

Runs the SAME full 7-step pipeline (baseline, walk-forward-aware GA search, re-validated Monte Carlo, out-of-sample check, holdout check, ICIR gate, report) against every strategy checked below, one after another -- the web equivalent of the desktop app's "RUN FULL PIPELINE (BATCH)" button. Uses the dataset and settings configured above; the single strategy picked in section 1 above is ignored when you click the batch button below.

Validates the dataset and selected strategies right now, then waits until this clock time (today, or tomorrow if it's already passed) before actually starting -- so you can queue an overnight batch without staying up for it. Runs today if the time hasn't passed yet, otherwise tomorrow.
